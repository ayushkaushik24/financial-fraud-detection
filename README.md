# AI Cyber Sentinel: Financial Fraud Detection System

An end-to-end Machine Learning pipeline and interactive real-time Web Dashboard built with Python and Streamlit to detect fraudulent credit card transactions.

##  Key Features
- **Real-Time Threat Simulator**: Ingests incoming transaction vectors and calculates risk probability.
- **Machine Learning Models**: Random Forest Classifier with `class_weight='balanced'` handling severe class imbalance.
- **Performance Benchmarks**: Achieved an **ROC AUC Score of 0.9573** with **91% Precision** and **79% Recall**.
- **Cyber Security SOC UI**: Built with Streamlit & custom CSS.

##  Tech Stack
- **Language**: Python 3.x
- **Libraries**: Pandas, NumPy, Scikit-Learn, Streamlit
